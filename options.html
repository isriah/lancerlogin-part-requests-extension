01 Connect Notion

NOT CONNECTED
Instructions for the workspace owner
  1. Create an internal connection in Notion's developer portal for the team's workspace.
  2. Enable Read content, Insert content, and Read user information without email addresses.
  3. Add the connection to the original ordering database using its Connections menu.
  4. Enter the connection token below on this computer. Use a test copy of the database for first-run checks.

Guests can use this owner-created connection. The connection creates requests; the Orderer/Recipient field identifies the requester.
